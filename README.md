## Описание проекта

Программа предназначена для автоматического размещения прямоугольных макроблоков на кристалле интегральной схемы.
В основе лежит представление топологии с помощью **парных последовательностей (Sequence Pair)**, декодирование в координаты через построение **горизонтального и вертикального графов ограничений (DAG)** и оптимизация целевой функции (суммарная длина связей HPWL + штраф за габариты) с помощью **генетического алгоритма**.

## Быстрый старт

### Требования к окружению
- Компилятор с поддержкой C++17 (MSVC 2022 / GCC 9+ / Clang 10+)
- CMake 3.20+
- Ninja или Visual Studio


> [!NOTE]
> Подробные инструкции по настройке окружения **[см. здесь](docs/USER_GUIDE.md)**.

### Сборка и запуск

```powershell
# 1. Конфигурация и сборка проекта в режиме Release
cmake -B build -S . -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release

# 2. Запуск оптимизации с генерацией JSON и векторного чертежа SVG
.\build\ga_sp_topology.exe --input data/sample_team1.json --output output.json --svg placement.svg
```

## Основные возможности

| Компонент | Используемый подход | Назначение |
| :--- | :--- | :--- |
| **Геометрический декодер** | Sequence Pair | Построение размещения без взаимных перекрытий блоков с выравниванием по сетке. |
| **Оценка размещения** | Предвыделенная память | Отсутствие динамических аллокаций памяти в основном цикле эволюции для максимальной скорости. |
| **Генетический алгоритм** | Селекция, скрещивание OX, элитизм | Оптимизация расположения блоков с возможностью параллельной оценки особей. |
| **Целевая функция** | Полупериметр связей (HPWL) | Минимизация длины проводников с учетом весов цепей и барьерный штраф за выход за пределы кристалла. |
| **Геометрический контроль** | Независимый верификатор | Контрольная проверка готового размещения на отсутствие коллизий, соблюдение границ и корректность сетки. |
| **Визуализация** | Экспорт в SVG | Создание векторного изображения кристалла с блоками, сеткой и связями. |

## Параметры командной строки (CLI)

| Параметр | По умолчанию | Описание |
| :--- | :--- | :--- |
| `--input <path>` | `data/sample_team1.json` | Путь к входному файлу топологического проекта. |
| `--output <path>` | `output.json` | Путь для сохранения результата оптимизации в JSON. |
| `--svg <path>` | `placement.svg` | Путь для сохранения векторного изображения размещения. |
| `--seed <int>` | `42` | Зерно генератора случайных чисел для воспроизводимости. |
| `--help` | — | Вывод справки по параметрам запуска. |

Пример запуска для схемы из 600 блоков:
```powershell
.\build\ga_sp_topology.exe --input data/test_hard_600.json --output out_hard.json --svg out_hard.svg --seed 1234
```

## Форматы данных

### Входной файл (JSON)
Входной файл содержит описание габаритов кристалла, перечень макроблоков, электрических цепей и параметров алгоритма:
- `design`: размеры кристалла (`chip_width`, `chip_height`), шаг сетки (`grid_size`), флаг разрешения вращения (`rotation_allowed`).
- `blocks`: список блоков с их идентификаторами и размерами (`width`, `height`).
- `nets`: список электрических цепей, соединяющих блоки, с указанием весов (`weight`).
- `ga_params`: параметры ГА (размер популяции, количество поколений, вероятности скрещивания и мутации).

### Выходной файл (JSON)
Результат работы включает:
- Итоговые координаты `(x, y)` и ориентацию каждого макроблока.
- Метрики качества: длину связей (HPWL), площадь охватывающего прямоугольника, плотность заполнения.
- Результат работы геометрического верификатора (`is_valid: true`).
- Телеметрию: время работы алгоритма в миллисекундах и пиковое потребление оперативной памяти (MB).
