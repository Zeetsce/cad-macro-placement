# САПР топологического проектирования СБИС (Двумерное размещение макроблоков)

Программный комплекс САПР для автоматизированного двумерного размещения прямоугольных макроблоков на кристалле методом генетического алгоритма (ГА) на базе парных последовательностей (Sequence Pair).

## Разработчики (Команда 1, группа ЭН-44)
- САПР топологического проектирования СБИС.

## Стек технологий
- **Язык:** C++17 (MSVC / GCC / Clang)
- **Система сборки:** CMake 3.20+
- **Сторонние зависимости:** `nlohmann/json` (header-only, сериализация/десериализация)

## Сборка и тестирование

### Требования
- CMake 3.20 или выше
- Компилятор с поддержкой C++17 (MSVC v143+ / Visual Studio 2022, GCC 9+, Clang 10+)
- Ninja или Visual Studio Generators

### Инструкция по сборке

```powershell
# Генерация проекта в режиме Release
cmake -B build -S . -DCMAKE_BUILD_TYPE=Release

# Сборка проекта
cmake --build build --config Release

# Запуск тестов
ctest --test-dir build -C Release --output-on-failure
```
